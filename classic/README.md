# 星燼艦隊 STARFALL ARMADA

深空艦隊戰術指揮遊戲 — 純網頁單機版，不需安裝、不需網路，雙擊即玩。

![類型](https://img.shields.io/badge/%E9%A1%9E%E5%9E%8B-%E5%8D%B3%E6%99%82%E6%88%B0%E8%A1%93-blue)

## 怎麼開始玩

**方法一**：雙擊「`啟動遊戲.bat`」
**方法二**：直接用瀏覽器（建議 Chrome / Edge）打開 `index.html`

進度會自動存在瀏覽器裡（同一台電腦、同一個瀏覽器就會記得）。

## 遊戲內容

| 模式 | 說明 |
|------|------|
| **戰役** | 8 關劇情任務：從邊境哨戒打到最終 BOSS「隕星號」決戰，含星雲遭遇戰、防衛站保衛戰、多波次伏擊 |
| **無盡遠征** | 破關後解鎖，敵軍一波比一波強，賺星幣、拚最佳紀錄（演習模式，艦隊不會真的損失） |
| **遭遇戰** | 自由設定雙方預算的沙盒對戰，所有艦種直接解鎖 |

### 經營你的艦隊
- 用**星幣**購艦：攔截機 / 飛彈護衛艦 / 光束驅逐艦 / 電漿巡洋艦 / 航空母艦 / 旗艦戰列艦，六種艦種互有剋制
- 戰役中損失的艦艇是**真的沒了**（會回收部分殘骸價值）；打不贏可以「撤退」保船
- 存活且擊墜 2 艘以上的艦艇會**晉升**（最多 ★3），永久提升火力與船體
- 出擊前可選 **楔形突擊 / 戰列橫隊 / 球形護衛** 三種陣型

### 戰鬥操作
| 操作 | 效果 |
|------|------|
| 左鍵拖曳 | 框選我方艦艇（雙擊＝選同型全部） |
| 右鍵 | 點敵艦＝集火、點空處＝移動 |
| 空白鍵 | **戰術暫停**（暫停中仍可下指令） |
| 1 ~ 4 | 選擇分隊（連按兩下＝鏡頭跳過去） |
| Q / W / E | 指揮官技能：軌道打擊 / 護盾湧流 / 躍遷增援 |
| 滾輪、中鍵拖曳、方向鍵 | 縮放、平移視角 |
| F | 鏡頭跟隨開關 |
| Esc | 選單 / 取消 |

艦艇不下令也會自動接戰（掛機也能打），下指令則能集火、誘敵、保護重艦——勝率差很多。

## 技術說明

- 純 HTML5 Canvas + 原生 JavaScript，**零外部依賴、零圖片音效素材**
- 所有戰艦造型皆為程式向量繪製、所有音效與背景音樂皆為 WebAudio 即時合成
- 檔案結構：
  - `index.html` — 頁面骨架
  - `css/style.css` — 介面樣式
  - `js/data.js` — 艦種數值、關卡、技能（想改平衡從這裡下手）
  - `js/entities.js` — 艦艇 AI 與射控
  - `js/battle.js` — 戰鬥引擎與繪製
  - `js/ui.js`、`js/main.js` — 介面與流程
  - `js/sprites.js`、`js/sfx.js`、`js/util.js` — 造型、音效、工具

想重置進度：主選單 →「重置進度」。
